# Phase 2.17: 一括操作

基準日: 2026-10-05。製品一括タグ更新のみ実装済み。

## 現行: 製品一括タグ更新（2.17.1）

製品一覧で複数選択し、BulkTagEditDialogから追加・上書き・削除を行う。

POST /api/products/bulk-update-tags（ログイン必須）:

~~~json
{
  "productIds": [1, 2],
  "mode": "add",
  "tagIds": [10, 11]
}
~~~

| mode | 操作 |
|---|---|
| add | 既存タグを保持して追加 |
| replace | 既存タグを削除し、指定タグに置換 |
| remove | 指定したタグのみ解除 |

製品ID・タグIDは空配列を拒否し、存在を確認する。
応答はsuccess、updatedCount、totalRequested、失敗があればerrors。
処理はPrismaトランザクション内で行うが、製品ごとの例外を捕捉するため、全対象の原子性・失敗時の応答保証は [リファクタリング計画R2](refactoring-plan.md) で整理する。
